# Checklist de Servicios Iglesia

Aplicacion web sencilla para organizar pendientes y checklist de servicios en la iglesia.

## Incluye

- Registro de tareas por area
- Responsable, fecha, prioridad y nota
- Estados: Pendiente, En proceso y Completado
- Filtros por area, estado, fecha y busqueda
- Plantillas rapidas para servicios comunes
- Guardado automatico en el navegador con `localStorage`

## Archivos principales

- `index.html`
- `styles.css`
- `app.js`

## Uso local

Abre `index.html` en tu navegador.
